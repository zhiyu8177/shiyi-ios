# 拾壹 iOS APP 编译说明

## 步骤

1. 登录 GitHub，新建一个仓库（名字随便，比如 `shiyi-ios`）
2. 把这个文件夹里的所有文件上传到仓库根目录（注意 `.github` 文件夹是隐藏的，别漏了）
3. 打开仓库的 **Actions** 标签页
4. 左边选 **Build IPA**，点 **Run workflow**
5. 等5-10分钟编译完成
6. 点进去这次运行，底部 **Artifacts** 里下载 `Shiyi-ipa.zip`
7. 解压得到 `Shiyi.ipa`
8. 用 iPhone 上的 TrollStore 导入安装

## 默认配置
- 服务器地址：`http://172.16.2.89:8899`（蒲公英虚拟IP）
- APP名称：拾壹（桌面图标名已修复，不再乱码）
- Bundle ID：com.shiyi.app

## 本版本功能（v1.1）
- **原生语音输入**：右上角麦克风按钮，点一下开始录音，再点一下停止并自动识别
  - 录音用 iOS 原生能力（不依赖网页权限，局域网 HTTP 下也能用）
  - 音频 16kHz WAV 直接发给电脑的 `/api/transcribe`，在拾壹本机识别
  - 识别文字自动填入输入框，确认后点发送
- 网页自带麦克风按钮在手机端自动隐藏（手机端统一用原生按钮）
- 界面适配刘海屏安全区，底部输入栏不再被 Home 条遮挡

## 注意
- 手机要保持蒲公英连接，才能访问到拾壹服务
- 电脑端拾壹要启动着，手机APP才能正常用
- 首次点麦克风识别约需 1 分钟（电脑加载语音模型），之后秒回
